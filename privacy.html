プライバシーポリシー

「Shigaku AI recordings」（以下「本ツール」）は、会議の録画を終了後に自動で整理するための社内用のツールです。本ツールが Google アカウントから受け取る情報の扱いを、次のとおり定めます。

受け取る情報

  • Google カレンダーの予定（件名・日時）。読むだけで、予定の作成や変更はしません
  • Google ドキュメントとスプレッドシートの内容。会議の記録（録画の保存先や書き起こしの置き場）を書き足すために読み書きします

使い方

受け取った情報は、録画がどの会議のものかを見分けることと、その会議の記録を所定の文書に書き足すことにだけ使います。広告や分析のために使うことはありません。

保存と共有

情報は、本ツールを運用する関係者の管理する機器と保存場所にのみ置きます。第三者に提供・販売することはありません。法令に基づく場合を除き、外部に開示しません。

Google API サービスの利用

本ツールによる Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

許可の取り消し

Google アカウントの「セキュリティ」→「サードパーティ製のアプリとサービス」から、いつでも本ツールのアクセスを取り消せます。
